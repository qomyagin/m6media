# Совместимость Haval M6 (2023 / M6 Plus)

Это практическая шпаргалка: какие файлы M6 обычно читает, какие нет и что
с ними делает `m6media`.

Источник официального списка: руководство Haval M6 Plus (2023–2026),
страница 116 ([скан](https://mcgrp.ru/files/viewer/1112377/117)).

## Официально заявленные форматы

| Тип | Форматы |
|---|---|
| Видео | WMV, MP4, MPEG, AVI, 3GP, MKV, MOV, ASF, VOB |
| Аудио | MP3, WMA, AAC, FLAC, WAV, OGG |
| Фото | JPG, PNG, BMP |
| USB | FAT16, FAT32 |

Список описывает **контейнеры и расширения**, а не кодеки. Поэтому файл
`.avi` с XviD может не играть, хотя AVI формально поддерживается.

## Целевой формат m6media

| Параметр | Значение |
|---|---|
| Контейнер | MP4 (`--container mkv` — альтернатива) |
| Видео | H.264 / AVC, Main@4.0, 8 бит, yuv420p, 4:2:0 |
| Размер кадра | до 1920×1080, без апскейла |
| Частота | до 30 fps (исходная, если ≤ 30) |
| Звук | AAC-LC, 48 кГц, stereo, 192 кбит/с |
| MP4 | `+faststart`, `mp42` |
| Имя | ASCII-транслитерация по умолчанию |

Это консервативный набор: он покрывает и H.264-файлы, которые M6 уже
воспроизводит, и проблемные AVI/XviD.

## Что реально важно

1. **Видеокодек.** H.264 — да. MPEG-4 Part 2 (XviD/DivX) — обычно нет.
   HEVC/H.265, VP9, AV1 — не гарантируются.
2. **Профиль и level H.264.** High@4.1 при 480p часто работает; для 1080p
   безопаснее Main@4.0.
3. **Битность и цвет.** 8-бит 4:2:0 (`yuv420p`); HDR/10-бит и 4:2:2 —
   риск чёрного экрана.
4. **Звук.** AAC-LC stereo — безопасно. AC3 в MKV на практике работает,
   AC3/DTS в MP4 — нет.
5. **Контейнер.** MKV и MP4 — основные рабочие; AVI — только если кодек
   внутри совместим.
6. **Файловая система.** FAT32/exFAT; NTFS — риск.

## Наблюдаемая матрица

| Файл | Контейнер | Видео | Звук | Результат |
|---|---|---|---|---|
| `movie-h264-1.mkv` | MKV | H.264 High@4.1, 480p | AC3 5.1 | играет |
| `movie-h264-2.mkv` | MKV | H.264 High@4.1, 480p | AC3 5.1 | играет |
| `movie-h264.mp4` | MP4 | H.264 Main@4.0, ≤1080p | AAC | играет |
| `movie-xvid-1.avi` | AVI | MPEG-4 Part 2 (XviD), 480p | AC3 5.1 | не играет |
| `movie-xvid-2.avi` | AVI | MPEG-4 Part 2 (XviD), 480p | AC3 5.1 | не играет |
| `movie-hdr.mkv` | MKV | H.264 10-bit/HDR | любое | риск чёрного экрана |
| `movie-1080p41.mp4` | MP4 | H.264 High@4.1, 1080p | AAC | риск |

Это наблюдения на конкретной прошивке, а не гарантия для всех M6.
Если файл нестандартный — проверяйте на своей машине.

## Симптом → причина → решение

| Симптом | Вероятная причина | Что делать |
|---|---|---|
| Файл не виден в меню | XviD/DivX, HEVC, HDR, битый файл | `./m6media.py /Volumes/USB` |
| Видео есть, звука нет | AC3/E-AC3/DTS в MP4 | скрипт делает AAC stereo |
| Чёрный экран, звук есть | профиль/level, 10-бит, 4:2:2 | перекодировать в Main@4.0 |
| Дёргается/тормозит | слишком высокий bitrate или 60 fps | `--preset compact` |
| Файл > 4 ГБ не копируется | FAT32 | exFAT или `--fat32 split` |
| Флешка не видна | NTFS/повреждение/разметка | FAT32, проверить диск |
| Часть файлов играет, часть нет | разные кодеки в одной папке | диагностика + конвертация только проблемных |

## Контейнеры

| Контейнер | Комментарий |
|---|---|
| MP4 | Основной целевой; `+faststart` важен для быстрого старта |
| MKV | Хорошо работает с H.264; может содержать AC3 |
| AVI | Поддерживается формально; XviD/DivX внутри — проблема |
| MOV/3GP | Обычно H.264/AAC, часто совместимы |
| WMV/ASF/VOB/MPEG | Лучше перепаковать/перекодировать в MP4 |

## Звук

| Кодек | Комментарий |
|---|---|
| AAC-LC | Целевой; stereo, 48 кГц |
| MP3 | Поддерживается; скрипт может перепаковать в MP3 |
| AC3 | Работает в MKV; в MP4 — перекодировать в AAC |
| E-AC3/DTS | Не гарантируется; перекодировать |
| FLAC/WAV/OGG | Заявлены; скрипт по умолчанию не трогает |
| WMA | Заявлен; скрипт не трогает |

## Флешка

* FAT32 — максимальная совместимость, но файл < 4 ГиБ.
* exFAT — часто работает и не имеет лимита 4 ГиБ; скрипт это учитывает.
* NTFS — обычно не читается; не использовать без проверки.
* Служебные `._*` от macOS безвредны, но можно убрать `dot_clean -m`.

## Как скрипт принимает решение

1. `ffprobe` читает контейнер, видео, звук, размер, fps, rotation, HDR.
2. Если видео и звук совместимы, файл пропускается (`skip-compatible`).
3. Если видео H.264 совместимо, а звук нет — `copy-video` (видео без
   потери качества, звук → AAC).
4. Если видео несовместимо — `transcode` в H.264 Main@4.0 + AAC.
5. Существующий целевой файл пропускается; `--force` перезаписывает.
