> **Haval M6 флешкадағы фильмді көрмей ме, AVI/XviD немесе MKV (AC3)
> ойнатпай ма?** Көбінесе мәселе exFAT-та немесе файл атында емес, кодекте:
> M6 AVI контейнерін қолдайды, бірақ MPEG-4 Part 2 (XviD/DivX) кодекін
> декодтай алмайды. `m6media` осындай файлдарды тауып, **тек соларды**
> H.264/AAC MP4 форматына түрлендіреді, жұмыс істеп тұрған файлдарды
> тиіспейді.

Скрипт Haval M6 (M6 Plus, Ресей басылымы 2023–2026) мультимедиасы үшін
бейне, музыка және суреттерді дайындайды, нақты файл неге көрсетілмейтінін
түсіндіреді және **macOS, Linux және Windows** жүйелерінде жұмыс істейді.

Нақты **exFAT флешкада** тексерілген: AVI/XviD көрсетілмеді, MKV/H.264
жұмыс істеді. Толығырақ — «Haval M6 неге AVI/XviD ойнатпайды» бөлімінде.

Пайдалы сілтемелер: [FAQ](FAQ.kk.md) · [үйлесімділік кестесі](docs/COMPATIBILITY.md) · [English](README.en.md)

## Скрипт не істейді

1. `ffprobe` арқылы контейнерді, кодектерді, өлшемді, fps және дыбысты
   анықтайды.
2. Файлды жай қайта қаптау/көшіру керек пе, әлде түрлендіру керек пе —
   соны шешеді. Сәйкес файл әдепкіде **өткізіледі** және шығыс қалтасында
   қайталанбайды.
3. **Сәйкес емес** бейнені мақсатты форматқа келтіреді:
   * MP4 (`+faststart`, `mp42`) немесе `--container mkv`;
   * H.264 Main@4.0, 8 бит, 4:2:0 (`yuv420p`), 1920×1080-ге дейін,
     30 fps-ке дейін, CRF 21 және битрейт шегі;
   * AAC-LC, 48 кГц, stereo, 192 кбит/с.
4. Сәйкес емес музыканы **MP3** (256 кбит/с, 44,1 кГц, stereo,
   ID3v2.3 + ID3v1) немесе AAC/M4A форматына келтіреді. Қолдаулы
   MP3/WMA/AAC/FLAC/WAV/OGG файлдарын тиіспейді.
5. Сәйкес емес суреттерді **JPEG** форматына келтіреді (macOS-та `sips`,
   Windows/Linux-та ImageMagick `magick`, қажет болса ffmpeg). Қолдаулы
   JPG/PNG/BMP файлдарын тиіспейді.
6. Нәтижені `Video/`, `Music/`, `Photo/` қалталарына салады.
7. Қажет болса бейнені **4 ГиБ-тан кіші бөліктерге** бөледі (FAT32 шегі).
   exFAT-та бөлу автоматты түрде өшеді.
8. `_m6media/manifest.json`, `manifest.csv`, `run.log` есептерін жазады
   және дайын қалтаны `--check-only` арқылы тексере алады.

Дереккөз файлдар **өзгертілмейді және жойылмайды**. Скрипт тек оқиды және
нәтижені көрсетілген қалтаға жазады.

Әдепкіде шығыс қалтасына **тек түрлендіру қажет болған файлдар** түседі.
Сәйкес файлдар өз орнында қалады. Барлығын бір форматқа келтіру үшін
`--normalize` қосыңыз.

## Haval M6 неге AVI/XviD ойнатпайды

Нақты ағындардың мысалы (файл аттары жалпыланған):

| Файл | Контейнер | Бейне | Дыбыс | Нәтиже |
|---|---|---|---|---|
| `movie-xvid-1.avi` | AVI | MPEG-4 ASP (XviD), 704×384, 23,976 | AC3 5.1 | көрсетілмеді |
| `movie-xvid-2.avi` | AVI | MPEG-4 ASP (XviD), 720×400, 23,976 | AC3 5.1 | көрсетілмеді |
| `movie-xvid-3.avi` | AVI | MPEG-4 ASP (XviD), 720×384, 24 | AC3 5.1 | көрсетілмеді |
| `movie-xvid-4.avi` | AVI | MPEG-4 ASP (XviD), 704×352, 24 | AC3 5.1 | көрсетілмеді |
| `movie-h264-1.mkv` | MKV | H.264 High@4.1, 1104×462, 24 | AC3 5.1 | ойнады |
| `movie-h264-2.mkv` | MKV | H.264 High@4.1, 1152×480, 24 | AC3 5.1 | ойнады |
| `movie-h264-3.mkv` | MKV | H.264 High@4.1, 1152×480, 23,976 | AC3 5.1 | ойнады |

**Қорытынды:** ойнамайтын файлдардың ортақ белгісі — **AVI + MPEG-4 Part 2
(XviD/DivX)**, ал жұмыс істейтіндері — **MKV + H.264**. Нұсқаулықта AVI
контейнері бар, бірақ XviD/DivX кодегі жоқ. H.264 (MP4/MKV) екі
айырмашылықты да жояды. Файл аты, өлшем, кириллица және exFAT — себеп емес.
AC3 5.1 MKV-да M6-да ойнайды, бірақ MP4 үшін AAC сенімдірек.

Скрипт бұл файлдармен не істейді:

* XviD/AVI → бейнені H.264 Main@4.0-ке, дыбысты AC3-тен AAC-қа түрлендіреді;
* H.264/MKV + AC3 → бейнені сапасыз жоғалтусыз көшіреді, контейнерді
  MP4-ке, дыбысты AC3-тен AAC-қа ауыстырады;
* өлшемді үлкейтпейді: 704×384 сол күйінде қалады.

### Есепте `copy-video` деген не?

`--normalize` кезінде скрипт сәйкес файлдарды да өңдейді. H.264/MKV+AC3
үшін бұл бейнені қайта кодтау емес, `copy-video`:

* H.264 бейне бит-бит көшіріледі (`-c:v copy`) — сапа өзгермейді;
* AC3 5.1 → AAC stereo;
* MKV → MP4.

Логта `-c:v copy` жолы көрінеді. Әдепкіде мұндай файлдар **өткізіледі**:
скрипт тек бейнені қайта кодтау қажет жерде ғана жұмыс істейді
(XviD/DivX, H.264 профилінен тыс, HDR және т. б.).

```bash
./m6media.py /Volumes/USB
```

## Орнату

Скрипт осы қалтада. macOS/Linux жүйесінде орындалатын етіп жасаңыз:

```bash
chmod +x m6media.py
```

Windows-та `chmod` қажет емес — `py -3 m6media.py` немесе
`python m6media.py` арқылы іске қосыңыз.

Python 3.9+ және `libx264`, `aac`, `libmp3lame` бар ffmpeg керек.

### macOS

```bash
brew install ffmpeg
# қажет болса, HEIC/RAW үшін:
brew install imagemagick
```

Тексеру:

```bash
ffmpeg -version
python3 --version
```

`--burn-subs` (субтитрлерді күйдіру) және `--tonemap` (HDR→SDR) үшін
`libass`/`zscale` бар жинақ керек. Қарапайым Homebrew ffmpeg-інде олар жоқ;
`ffmpeg-full` орнатып, жолын көрсетуге болады:

```bash
brew install ffmpeg-full
./m6media.py … --ffmpeg /opt/homebrew/opt/ffmpeg-full/bin/ffmpeg \
                 --ffprobe /opt/homebrew/opt/ffmpeg-full/bin/ffprobe
```

### Linux

```bash
sudo apt install ffmpeg       # Debian/Ubuntu
sudo dnf install ffmpeg       # Fedora
# қажет болса, HEIC/RAW үшін:
sudo apt install imagemagick
```

### Windows

```powershell
winget install Gyan.FFmpeg
# қажет болса, HEIC/RAW үшін:
winget install ImageMagick.ImageMagick
```

Скрипт `ffmpeg`-ті `PATH`, `/opt/homebrew/bin`, `/usr/local/bin`,
`C:\ffmpeg\bin`, `C:\Program Files\ffmpeg\bin`, Chocolatey/WinGet ішінен
іздейді. Нақты жолды `--ffmpeg PATH`, `--ffprobe PATH` арқылы беруге болады.

## Жылдам бастау

### 1. Флешканы диагностикалау (ештеңе жазбайды)

macOS/Linux:

```bash
python3 m6media.py /Volumes/USB --diagnose
# Linux: python3 m6media.py /media/$USER/USB --diagnose
```

Windows (PowerShell, флешка `E:`):

```powershell
py -3 m6media.py E:\ --diagnose
```

Windows-та жол — дискі әрпі (`E:\`), шығыс — `E:\M6`.

Скрипт әр файл бойынша контейнерді, кодектерді, өлшемді, дыбысты,
әрекетті және себебін көрсетеді. Бұл файл неге көрінбейтінін түсінудің ең
қарапайым жолы.

### 2. Тек мәселелі файлдарды дайындау

```bash
python3 m6media.py /Volumes/USB
```

Windows:

```powershell
py -3 m6media.py E:\
```

Linux:

```bash
python3 m6media.py /media/$USER/USB
```

`M6` қалтасы дереккөздердің жанында автоматты түрде жасалады. Әдепкіде
скрипт:

* **сәйкес файлдарды өткізеді** — MKV/H.264, MP3/FLAC/WAV, JPG/PNG/BMP;
* **қызметтік файлдарды өткізеді** — `.srt`, `._*`, фильм жанындағы
  сыртқы `.ac3`;
* **тек сәйкес емес файлдарды өңдейді** — мысалы, AVI/XviD;
* exFAT-ты өзі анықтайды және файлдарды 4 ГиБ бойынша бөлмейді.

`M6` ішінде тек түзетілген сәйкес емес файлдар болады. Сәйкес MKV
файлдары өз орнында қалады және қайталанбайды.

Қосымша мүмкіндіктер:

```bash
# жылдамырақ (480p үшін сапа айырмашылығы аз)
... --x264-preset veryfast

# нәтижені бірден тексеру
... --check

# барлығын бір форматқа келтіру
... --normalize
```

### 3. Дайын нәтижені тексеру

```bash
python3 m6media.py /Volumes/USB/M6 --check-only
# Windows: py -3 m6media.py E:\M6 --check-only
```

### 4. Локалды дайындау (кейін флешкаға көшіру)

```bash
python3 m6media.py ~/Movies -o ~/m6-ready --preset compat
```

Егер мақсатты флешка exFAT болса, локалды дайындау кезінде:

```bash
python3 m6media.py ~/Movies -o ~/m6-ready --fat32 off
```

## Қайта іске қосу және `--force`

Егер `M6` ішінде дәл сол атпен файл болса, скрипт оны **тиіспейді**:
«файл уже существует…» деп жазады және жалғастырады. Қайта жазу үшін:

```bash
./m6media.py /Volumes/USB --force
```

`--force` тек скрипт өңдейтін файлдарды қайта жазады. Сәйкес файлдар бәрібір
өткізіледі; оларды да қайта жазу үшін `--normalize --force`.

## Мысалдар

### Тек сәйкес емес файлдар

```bash
python3 m6media.py /Volumes/USB --only video
```

Қолмен тізім беру:

```bash
python3 m6media.py "/Volumes/USB/Movie 1.avi" "/Volumes/USB/Movie 2.avi"
```

### Барлығын қайта кодтау

```bash
python3 m6media.py ~/Movies -o ~/m6-ready --mode encode --preset quality
```

### Бастапқы атауларды сақтау (кириллица, бос орын)

```bash
python3 m6media.py ~/Movies -o ~/m6-ready --keep-names
```

Әдепкіде атаулар ASCII-ге транслитерацияланады, **номірсіз**:
`Pinokkio_Gilermo_del_Toro_2022.mp4`. Тұрақты рет керек болса, `--number`
қосып, `001_Pinokkio...mp4` алыңыз. M6 кириллицаны көрсетеді, сондықтан
`--keep-names` те жұмыс істейді.

### Тек музыка / тек сурет

```bash
python3 m6media.py ~/Music -o ~/m6-ready --only audio
python3 m6media.py ~/Photos -o ~/m6-ready --only image
```

Сәйкес MP3/WMA/AAC/FLAC/WAV/OGG және JPG/PNG/BMP әдепкіде тиіспейді.
MP3-ке қайта коду немесе суретті кішірейту үшін `--normalize` қосыңыз.

### Файл сәйкес пе — жылдам тексеру

```bash
python3 m6media.py file.mkv --dry-run
```

| `--force` | — | дайын файлдарды қайта жазу |
| `--keep-names` | — | атауларды транслитерацияламау |
| `--number` | — | `001_`, `002_` нөмірлерін қосу |
| `--check` | — | өңдеуден кейін тексеру |
| `--check-only` | — | дайын қалтаны ғана тексеру |

| `--tonemap` | — | HDR→SDR (zscale керек) |
| `--usb` | — | USB-ге шығару; ФС пен орынды тексеру |

| Профиль | Өлшем | CRF | Бейне шегі | Дыбыс |

| `quality` | 1920×1080 | 19 | 12 Мбит/с | AAC 256k |
| `compact` | 1280×720 | 23 | 3 Мбит/с | AAC 128k |

## FAT32 үшін бөлу

FAT32 4 ГиБ-тан үлкен файлды қабылдамайды. Скрипт ұзақтық пен битрейтті
есептеп, нұсқа таңдайды:

* `fit` (FAT үшін әдепкі) — бір фильм `--max-file-size` ішіне сыйатындай
  битрейтті төмендетеді. Егер шек тым төмен болса (1080p үшін 2,2 Мбит/с,
  720p үшін 1,2 Мбит/с), бөлу қосылады;
* `split` — сапаны сақтап, тең бөліктерге бөледі
  (`..._part01.mp4`, `..._part02.mp4`);
* `off` — шектемеу (exFAT/NTFS/локалды диск).

Кодтаудан кейін скрипт нақты өлшемді қайта тексереді. Файл әлі үлкен болса,
бөліктер санын көбейтіп қайта кодайды.

exFAT флешкада бөлу қажет емес: файлдар 4 ГиБ-тан үлкен болуы мүмкін.

## Нәтиже құрылымы

```text
M6/
├── Video/
│   ├── movie-xvid-1.mp4
│   └── ...
├── Music/                 # тек конвертация болса
├── Photo/                 # тек конвертация болса
└── _m6media/
    ├── manifest.json      # толық есеп: дереккөз, ағындар, әрекеттер
    ├── manifest.csv       # Excel үшін
    └── run.log            # журнал
```

Мұнда тек нақты конвертацияланған файлдар бар. Сәйкес файлдар өз орнында
қалады — шығыс қалтасына көшірілмейді. `--normalize` кезінде толық жиын
болады.

`_m6media` қалтасын флешканы машинаға салмас бұрын жоюға болады, бірақ
есеп талдау үшін пайдалы.

---

## Неге H.264 Main@4.0 және AAC

* **H.264** — M6 H.264 High@4.1 (MKV) ойнатады. Main@4.0 — қарапайым және
  кең тараған профиль.
* **AAC-LC** — нұсқаулықта бар; AC3/DTS MP4-те нашар қолдаулы, сондықтан
  дыбыс әрдайым AAC-қа келтіріледі.
* **8 бит 4:2:0** — HDR/10-бит және 4:2:2/4:4:4 автомобиль плеерлерінде
  жиі ойналмайды.
* **MP4 + faststart** — `moov` файл басында, плеер тезірек бастайды.
* **Субтитрлер әдепкіде жоқ** — кірістірілген субтитрлер алынып тасталады.
  Қажет болса `--burn-subs` (libass керек).

---

## Жылдамдық: неге ұзақ және қалай жылдамдатуға болады

Бірнеше фильмді қайта кодтау — бұл көшіру емес, сағаттарға созылатын
жұмыс. 8 ядролы Mac-та 4 тапсырманы қатар іске қосып, нәтижені сол USB
флешкаға жазсаңыз:

* 4 x264 процесі CPU үшін бәсекелеседі (ескі нұсқада әрқайсысы ~12 ағын
  алатын, load average ~48-ге жететін);
* 4 файл бір уақытта флешкадан оқылып, сол флешкаға жазылады — USB тар
  жер болады;
* әр файлдың соңында `+faststart` бүкіл MP4-ті қайта жазады — USB-та бұл
  минустар қосады.

Жаңа нұсқада әдепкіде 2 тапсырма, ал x264 `ядро / jobs` ағынынан
аспайды. USB үшін тағы жылдамырақ:

```bash
./m6media.py /Volumes/USB --jobs 2 --x264-preset veryfast
```

Ең жоғары жылдамдық үшін нәтижені локалды дискке жазып, кейін флешкаға
көшіріңіз:

```bash
./m6media.py /Volumes/USB -o ~/M6 --jobs 2 --x264-preset veryfast
```

Сонда флешкадан тек оқу жүреді, ал жазу жылдам SSD-ге барады.

## Флешка бойынша кеңестер

* Қалталарды 2–3 деңгейден тереңдетпеңіз: `M6/Video`, `M6/Music`,
  `M6/Photo`.
* Ойнату кезінде флешканы суырып алмаңыз — M6 нұсқаулығы құрылғыны
  танымауы мүмкін екенін ескертеді.
* macOS-та FAT/exFAT-қа көшіргеннен кейін `._имя` қызметтік файлдары
  пайда болады. Олар зиянсыз, бірақ мына командамен тазалауға болады:

  ```bash
  dot_clean -m /Volumes/USB
  ```

  (немесе `find /Volumes/USB -name '._*' -delete`). Windows/Linux-та бұл
  файлдар әдетте пайда болмайды.
* Шығару алдында Finder-де «Шығару» / `diskutil eject` қолданыңыз.
* Егер M6 флешканы мүлдем көрмесе: FAT32/exFAT, MBR бөлімдеуін және
  құрылғы көлемін тексеріңіз. Скрипт флешканы форматтамайды.

---

## Шектеулер

* DRM-қорғалған файлдар (Apple Video, Amazon және т. б.) қолдаулы емес.
* Бүлінген/толық жүктелмеген файл оқылмауы мүмкін — скрипт қатені
  көрсетіп, қалғандарын жалғастырады.
* Бірінші аудио жол және бірінші бейне алынады; қалғандары тасталады.
  Сыртқы `.ac3` қосылмайды.
* Тараулар жойылады (`-map_chapters -1`).
* Субтитрлер: кірістірілгендер жойылады; сыртқыларды тек libass бар ffmpeg
  көмегімен күйдіруге болады.
* HDR→SDR `--tonemap`/zscale болмаса, түстер бозаң көрінуі мүмкін.
* Әдепкіде сәйкес файлдар шығыс қалтасына **көшірілмейді** — олар өз
  орнында қалады. Бұл қате емес; толық көшірме үшін `--normalize`.
* Скрипт флешканы форматтамайды. M6 көрмесе, FAT32 (немесе жұмыс істеп
  тұрған exFAT) етіп форматтап, қауіпсіз шығарыңыз.

## Тексеру және есептер

```bash
# өңдеуден кейін
python3 m6media.py ~/Movies -o ~/m6-ready --check

# дайын қалтаны бөлек тексеру
python3 m6media.py ~/m6-ready --check-only

# не істелгенін көру
python3 -m json.tool ~/m6-ready/_m6media/manifest.json | less
```

`--check` әр шығыс файлды қайта оқып тексереді:

* MP4 контейнері;
* H.264, профиль/level, `yuv420p`, өлшем, fps;
* AAC-LC, ≤ 2 арна;
* файл шегі;
* ұзақтық (бөлінбеген файлдар үшін);
* JPEG және сурет өлшемі.
